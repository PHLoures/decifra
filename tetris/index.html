Como jogar

  1. Encaixe as peças que vão caindo. Uma linha completa some e vale pontos; 4 linhas de uma vez é um Tetris.
  2. No teclado: ← → ou A D movem, ↓ ou S desce mais rápido, espaço solta de vez, ↑, W ou X gira, Z ou Q gira para o outro lado, C guarda a peça e P pausa.
  3. No celular: use os botões embaixo, ou toque no campo para girar, arraste para os lados para mover e deslize para baixo para soltar.
  4. A sombra mostra onde a peça vai cair. A cada 10 linhas o nível sobe e as peças caem mais rápido.
